# Quality Validator 사용자 설명서

병원 담당자가 코호트 데이터를 제출하기 전에 스스로 품질을 점검하는 프로그램입니다. 코호트 테이블 파일(질환 본표와 환자·방문·약물·검사 등 공통 표)을 넣고 실행하면 의뢰사 매뉴얼(2026-11-16) 기반 검증 규칙 390개(코호트마다 253~294개가 적용)를 검사해 보고서를 만듭니다.

- 병원 데이터베이스에 접속하지 않습니다. 내보낸 파일만 읽습니다.
- 네트워크 통신을 하지 않습니다. 결과는 사용자 컴퓨터에만 저장됩니다.
- 환자 단위 정보는 프로그램 밖으로 나가지 않습니다. 중앙에 보내는 파일은 집계만 담은 `submission.json` 하나입니다.

## 데이터가 오가는 길

```
코호트 테이블 (PERSON · VISIT_OCCURRENCE · … · 질환 본표 · SACT …)  ──→  검증 실행  →  보고서 · submission.json
  병원이 매뉴얼 양식에 맞춰 직접 채움 (CSV · 엑셀 · 폴더)
```

병원은 **표를 직접 채웁니다.** 코호트마다 질환 본표 하나와 OMOP 형식 공통 표(PERSON, VISIT_OCCURRENCE, PROCEDURE_OCCURRENCE, DRUG_EXPOSURE, CONDITION_OCCURRENCE, MEASUREMENT, OBSERVATION, NOTE), ADVERSE_EVENT, 항암요법 SACT(폐암·유방암·대장암·림프종)를 만들어 **검증 실행** 화면에 넣습니다.

## 화면 구성

왼쪽 메뉴에 7개 화면이 있습니다. 처음 열면 **검증 실행** 화면이 나옵니다.

| 메뉴 | 용도 |
|---|---|
| 검증 실행 | 코호트와 파일을 넣고 검증을 실행합니다. 결과 파일을 내보냅니다 |
| 결과 보고서 | 실행 요약, 실패 규칙, 분류별 집계, 보고서 원문 |
| 오류 현황 조회 | 위반 행을 규칙·테이블·심각도로 걸러 보고 CSV로 내보냅니다 |
| 대시보드 | 오류 유형별 통계, 질환별 최신 결과, 적용 규칙, 후속 조치 가이드, 실행 추이 |
| 통계 모니터링 | 실행 이력 목록과 위반 건수·오류율 추이, 실행 기록 삭제 |
| 검증 규칙 관리 | 규칙 조회·검색, 규칙 설명과 조치 안내, 규칙 켜고 끄기·값 조정·규칙 추가 |
| 설정 | 명세·규칙 위치, 검증 실행일 기본값, 데이터 저장 위치, 관리자 모드 |

## 검증 기준

검증 기준은 하나입니다. 의뢰사 **「질환별 데이터 테이블」 매뉴얼 2026-11-16** 이며 표 16개 · 필드 157개, 규칙 390개(구조 368 + 교차 22)입니다. 매뉴얼에 적힌 것의 위반은 **오류**, 임상 상식 범위나 OMOP 대표 코드 같은 매뉴얼 밖 제약의 위반은 **경고**로 표시합니다([4장](04-output.md)). 규칙의 구성은 [docs/spec-and-rules.md](../docs/spec-and-rules.md)에 있습니다.
