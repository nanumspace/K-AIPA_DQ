## 변경 사항

- **명세 조회:** 기존 검증 규칙 관리에 적용 명세·컬럼별 규칙 조회를 추가했습니다. 테이블·필드의 자료형·필수 여부·설명·범위·참조·허용 코드에서 해당 규칙으로 이동합니다. 별도 규칙 편집 메뉴를 중복 생성하지 않았습니다.
- **검증 기준 패키지:** 설정의 개발용 `spec/`, `rules/` 경로 선택을 없앴습니다. 기본 기준은 내장되어 있으며, 중앙이 배포한 ZIP 하나로 명세·규칙·코드표·보조 목록 전체를 가져옵니다. 적용 전 형식·지문·호환성·참조 관계와 명세/규칙 일관성을 검사하고 변경 내용을 표시합니다.
- **기관 조정 충돌:** 기준 변경과 충돌하는 조정을 조용히 재적용하지 않습니다. 취소하거나 기관 조정 전체 초기화에 동의해야 적용됩니다. 충돌하지 않는 조정은 유지하며, 변경 전후 내용은 이력에 기록합니다.
- **실행 당시 기준:** 실행마다 원본 YAML ZIP과 실효 명세·규칙·기관 조정·기준일·해시·관리자 모드를 보관하고 엔진도 실행 전용 사본을 사용합니다. 보고서와 위반 상세는 당시 기준으로 설명합니다. 원본을 보관하지 않은 이전 실행에는 현재 기준을 대신 표시하지 않습니다.
- **CSV 양식 저장:** 헤더만 있는 CSV 양식 버튼이 실제 ZIP 저장 대화상자를 열도록 수정했습니다. 저장 성공·취소·오류를 해당 화면에 안내합니다.

## 사용 방법

- 명세 확인: **검증 규칙 관리 → 적용 명세 · 컬럼별 규칙 보기**
- 기준 갱신: **설정 → 검증 기준 패키지 → 기준 패키지 가져오기 → 변경·충돌 확인 → 적용**
- 기관별 조정: 기존 **검증 규칙 관리** 및 JSON 설정 내보내기·가져오기를 사용합니다. 전체 기준 ZIP과 기관 조정 JSON은 다른 파일입니다.
- 과거 기준 확인: **결과 보고서 → 실행 당시 적용 기준**. `criteria.zip`, `criteria-snapshot.json`은 결과 묶음에도 포함되며 기관 내부 보관용입니다.

기준 패키지에는 환자 데이터와 기관 조정을 넣지 않습니다. 실행 스냅샷에는 기관 규칙·SQL 등이 포함될 수 있으므로 외부 제출하지 않습니다. 배포자 표기·해시는 출처 인증이 아니며 공식 배포 경로를 확인해야 합니다. 관리자 모드는 기존처럼 버튼으로 켜며 인증·승인 장치가 아닙니다.
