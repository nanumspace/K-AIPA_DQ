## 변경 사항

- **CSV 인코딩 판정 개선:** 인코딩을 파일 전체를 기준으로 판정합니다. 먼저 엄격한 UTF-8로, 안 되면 엄격한 CP949로 읽습니다. 두 방식 모두로 읽을 수 없는 파일, 또는 UTF-8 BOM이 있는데 본문이 UTF-8이 아닌 파일은 문자를 몰래 대체하지 않고 사전 점검 단계에서 오류로 중단합니다. 이전에는 한글이 처음 512KB 뒤에만 나오는 CP949 파일을 UTF-8로 읽어 한글이 U+FFFD로 깨졌습니다.
- **기본 검증 기준일을 한국 날짜로:** 기본 검증 기준일이 Asia/Seoul 달력 날짜를 사용합니다. 이전에는 UTC 날짜여서 오전 9시(KST) 이전에는 기본값이 어제였고, 당일 기록이 ST-0038 같은 미래 날짜 규칙에 걸릴 수 있었습니다. 사용자가 고르거나 저장한 날짜는 그대로 우선합니다.
- **사전 점검 행 수:** 사전 점검의 행 수에서 빈 줄을 제외합니다.
- **엔진 범위 재정의 테스트:** 엔진의 범위 재정의(range override) 테스트를 바로잡았습니다.

DQ 검증 규칙은 440개(구조 410 + 교차 30)로 그대로이며 코호트별 적용 규칙은 302~343개입니다. 규칙, 스키마, 제출 JSON, 충실도 41개 항목은 바뀌지 않았습니다.
