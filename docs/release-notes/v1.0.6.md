## 변경 사항

- **DQ 검증 규칙 436개(구조 410 + 교차 26):** 단위 경고 규칙 두 개를 추가했습니다. 둘 다 경고이며 오류·합격 기준은 바뀌지 않습니다.
  - `SEM-MEAS-003` 단위 부적합: 숫자 결과가 있는 HbA1c(%, mmol/mol), 혈청·혈장 크레아티닌(mg/dL, umol/L), 소변 알부민/크레아티닌 질량비(mg/g, mg/g{creat}, ug/mg, mg/mmol)의 `unit_concept_id` 가 해당 개념의 허용 목록에 없으면 알립니다. 허용 목록에 없는 검사 코드(정성, 시험지, 검출한계, 몰비 등)는 검사하지 않습니다.
  - `SEM-MEAS-004` 단위 없음: 같은 개념 목록의 검사에 숫자 결과는 있으나 `unit_concept_id` 가 비어 있으면 알립니다. 단위 불일치와 분리한 안내입니다.
  - 코호트별 적용 규칙은 298~339개입니다.
- **데이터 충실도 29개(공통 5 + 질환별 24):** 항목 두 개를 추가했습니다.
  - `EXP-MASLD-04` FIB-4 계산 가능: 기준일 전 365일~후 90일의 같은 날에 AST·ALT(U/L)·혈소판(10^3/uL 동등 단위)이 모두 0보다 큰 수치이고 `PERSON.age_at_index` 가 0보다 크면 충족입니다. 기존 `EXP-MASLD-01`의 검사 기록 유무와 별개로, 실제로 FIB-4를 계산할 수 있는지 봅니다.
  - `EXP-LY-04` 진단 시 림프종 병기: 기준일 전후 90일에 림프종 병기(SNOMED `4299327`) 측정 결과가 값과 함께 1회 이상 있으면 충족입니다. 범용 병기군이나 Tumor stage 개념은 림프종 병기로 추론하지 않습니다.

새 필수 입력이나 합격 기준은 없습니다.
