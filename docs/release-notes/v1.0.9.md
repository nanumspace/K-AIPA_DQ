## 변경 사항

- **ER·PR 백분율 표기(유방암):** ER·PR 결과가 백분율로 기록된 경우를 인식하도록 바이오마커 판정을 개선했습니다.
- **출생 전 연도 검증:** 출생 연도보다 이른 연도의 기록을 잡아내는 검증을 추가했습니다.
- **FIB-4 사유 표시(MASLD):** FIB-4를 계산하지 못한 경우 그 사유(필요한 값 누락 등)를 함께 보여 줍니다.
- **DQ 검증 규칙 440개(구조 410 + 교차 30):** 코호트별 적용 규칙은 302~343개이며 폐암은 334개입니다. 데이터 충실도는 41개로 그대로입니다.

입력·출력 스키마는 바뀌지 않았고 새 필수 입력이나 합격 기준은 없습니다.
