## 변경 사항

- **EGFR·ALK 검사 결과 기준 개정(폐암):** 첫 항암(SACT) 전 EGFR·ALK 검사 기록률은 검사 행이 있어도 구조화된 결과값이 없으면 기록으로 세지 않도록 기준을 바꿨습니다. 결과 없이 검사 행만 있는 경우는 따로 구분해 보여 줍니다.
- **구조화 결과 지표 6개 추가:** 바이오마커가 구조화된 결과로 기록됐는지와 원문에만 있는지를 구분하는 지표를 추가했습니다. 데이터 충실도는 41개(공통 5 + 질환별 36)입니다.
- **중복 측정 경고:** 같은 환자·검사·날짜의 중복 측정 기록을 알리는 교차 테이블 규칙을 추가했습니다. 경고이며 오류·합격 기준은 바뀌지 않습니다.
- **DQ 검증 규칙 438개(구조 410 + 교차 28):** 코호트별 적용 규칙은 300~341개이며 폐암은 332개입니다.

새 필수 입력이나 합격 기준은 없습니다.
