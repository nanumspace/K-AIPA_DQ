## 변경 사항

- **표준 어휘 기준:** 기준 어휘를 OHDSI 표준 어휘 **v20260829**로 고정했습니다. 진단·시술·이상사례는 SNOMED CT, 검사는 LOINC, 약물은 RxNorm·RxNorm Extension, 단위는 UCUM, 항암 요법은 HemOnc, 노트 분류는 LOINC 문서 분류입니다. 자세한 방침은 [docs/vocabulary.md](https://github.com/nanumspace/K-AIPA_DQ/blob/v1.0.2/docs/vocabulary.md)에 있습니다.
- **코드 목록 수정 (검증 결과가 달라질 수 있음):** 앱이 검사하는 코드 목록 중 어휘와 맞지 않던 값을 고쳤습니다.
  - `NOTE.note_type_concept_id`: 옛 Note Type 값(44814637, 44814640, 44814641, 44814645)을 표준 Type Concept 값으로 바꿨습니다(32841 EHR radiology report, 32835 EHR Pathology report, 32824 EHR discharge summary, 32834 EHR outpatient note). 32817, 32831 은 그대로입니다.
  - `NOTE.note_class_concept_id`: 다른 개념을 가리키던 값(36716164, 36716165, 36716213, 36716177, 44814641, 3040218)을 LOINC 문서 분류로 바꿨습니다(46235057 Radiology Note, 3031451 Pathology Note, 3020091 Discharge summary, 3000735 Progress note, 3030624 Outpatient Note, 3032377 Oncology Note). 0(분류 없음)은 그대로입니다.
  - 단위: mmol 8573(대체된 개념) → 9573, 10^6/uL 8847(어휘에 없음) → 8815.
  - 옛 값을 쓰는 데이터는 이제 해당 코드 목록 규칙(경고)에 걸립니다. 기준 어휘의 표준 개념으로 매핑해 주세요.
- **견본 데이터:** 가상데이터 카탈로그의 개념 59개가 이름과 다른 개념이거나 비표준·폐기 개념이어서 모두 기준 어휘의 표준 개념으로 바꾸고 견본(clean·dirty·Good Sample)을 다시 만들었습니다. 관찰(ECOG·흡연·생활습관 상담)과 노트 개념도 표준 개념으로 바꿨고, 항암 요법은 HemOnc 개념을 넣었습니다(HemOnc 에 같은 요법이 없는 3종은 0).
- **검증 기준 패키지 1.0.2:** 위 코드 목록과 카탈로그가 바뀐 기준입니다. 1.0.1 앱에서도 가져올 수 있습니다.
