## 변경 사항

- **DQ 검증 규칙 434개(구조 410 + 교차 24):** `SEM-DM-001`은 당뇨병 진단 종료일이 시작일보다 앞서면 오류로 보고합니다. 종료일은 여전히 선택입니다.
- **표준 개념 미매핑률:** 필드별 정수 개념 ID 중 `0`의 비율을 표시합니다. 빈 값과 형식 오류는 분모에서 제외하며, 미매핑 자체는 위반으로 세지 않습니다. 중앙 제출 파일에는 집계만 포함됩니다.
- **데이터 충실도 27개:** 당뇨병 연간 UACR(소변 알부민/크레아티닌비), 혈압, 신장기능, 지질, 체중의 충족도를 따로 표시합니다. 기존 연간 종합 지표는 유지하며 UACR은 종합 지표의 요건이 아닙니다.

새 필수 입력이나 합격 기준은 없습니다.
