## 변경 사항

- **report.pdf 추가:** 실행이 끝나면 report.md와 같은 내용을 담은 A4 PDF `report.pdf`를 만듭니다. 머리글에 실행 ID가 있고, 쪽 번호가 붙으며, 표가 여러 쪽에 걸치면 표 머리글을 반복합니다. 이전에 실행한 결과는 출력물 목록을 열 때, '결과 보고서 > PDF 저장'을 누를 때, 또는 내부용 묶음을 내보낼 때 report.pdf가 만들어집니다. report.md와 같은 방식으로 공유할 수 있으며 환자 단위 데이터는 들어 있지 않습니다. 이에 따라 출력물은 7종이 되었습니다. PDF는 앱에서만 만들며, CLI 엔진은 달라지지 않았습니다.
- **화면 이동은 왼쪽 사이드바로만:** 화면 간 이동을 왼쪽 사이드바로 일원화하고 중복되던 화면 안 버튼을 없앴습니다. 최근 실행 안내 배너, 위반 상세와 결과 보고서의 서로 이동 버튼, 대시보드의 상세 보고서·전체 보기 버튼, 통계 모니터링의 행별 버튼이 해당합니다. 규칙 이름을 누르면 해당 규칙의 위반 내역으로, 코호트 이름을 누르면 그 실행의 보고서로 이동하는 드릴다운은 그대로 둡니다. 결과 보고서와 위반 상세는 선택한 실행을 함께 사용합니다.

DQ 검증 규칙은 440개(구조 410 + 교차 30)로 그대로이며 코호트별 적용 규칙은 302~343개입니다. 상태 판정 규칙, 스키마, 제출 JSON, 충실도 41개 항목은 바뀌지 않았습니다.
